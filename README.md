# Python SQL Customer Manager API

A small backend project built with Python, SQL, and FastAPI.

## Goal

The goal of this project is to practice backend fundamentals:

- Python basics
- SQL CRUD operations
- Relational databases
- API design
- Git workflow

## Planned features

- Create customer
- List customers
- Get customer by ID
- Update customer
- Delete customer
- Search customers
- Store customers in a relational database
